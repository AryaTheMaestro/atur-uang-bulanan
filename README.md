# Atur Uang Bulanan

Simulasi pembagian uang bulanan (kebutuhan, keinginan, tabungan) yang bisa diatur sendiri, dibuat dengan satu file HTML tanpa library tambahan.

## Fitur
- Atur pembagian lewat slider persen atau rasio (misalnya 5 : 3 : 2)
- Centang atau matikan tiap kategori (makan, transportasi, dan lainnya)
- Ketik nominal per kategori, plus nominal per hari untuk makan dan transportasi
- Kategori yang sudah diedit otomatis terkunci (bisa dibuka lagi lewat centang Kunci)
- Pembulatan ke Rp5.000 terdekat
- Slider dan rasio di atas otomatis mengikuti perubahan di daftar kategori
- Proyeksi tabungan 3, 6, dan 12 bulan

## Cara pakai
Buka `index.html` di browser. Tidak perlu install apa pun.

## Hosting gratis dengan GitHub Pages
Settings > Pages > Source: Deploy from a branch > branch `main`, folder `/ (root)` > Save.
